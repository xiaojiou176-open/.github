# xiaojiou176-open

Open-source local-first AI tools for browser automation, traceable research, and operator workflows.

This organization is the public showcase for systems I want to be understandable from the outside: products with visible state, inspectable evidence, practical operator surfaces, and a clear story about what they are trying to solve.

Built by [Terry Yu](https://github.com/xiaojiou176).

## What this org is about

The repositories here are not random experiments. They cluster into a few connected product lines:

| Product line | Repositories | What they are for |
| --- | --- | --- |
| Orchestration and control planes | [CortexPilot-public](https://github.com/xiaojiou176-open/CortexPilot-public), [ui-automation-control-plane](https://github.com/xiaojiou176-open/ui-automation-control-plane) | Governing AI and automation work with evidence, replay, and operator visibility |
| Auditable browser workflows | [prooftrail](https://github.com/xiaojiou176-open/prooftrail), [ui-automation-control-plane](https://github.com/xiaojiou176-open/ui-automation-control-plane) | Turning browser flows into repeatable proof instead of black-box automation |
| Traceable research and knowledge systems | [sourceharbor](https://github.com/xiaojiou176-open/sourceharbor), [provenote](https://github.com/xiaojiou176-open/provenote), [docsiphon](https://github.com/xiaojiou176-open/docsiphon) | Building search, writing, and knowledge workflows that preserve sources and auditability |
| Product-facing AI tools | [openui-mcp-studio](https://github.com/xiaojiou176-open/openui-mcp-studio), [multi-ai-sidepanel](https://github.com/xiaojiou176-open/multi-ai-sidepanel), [campus-copilot](https://github.com/xiaojiou176-open/campus-copilot) | Bringing AI systems closer to real operator and end-user workflows |
| Local-first macOS and utility products | [apple-notes-snapshot](https://github.com/xiaojiou176-open/apple-notes-snapshot), [apple-notes-forensics](https://github.com/xiaojiou176-open/apple-notes-forensics), [dealwatch](https://github.com/xiaojiou176-open/dealwatch) | Useful software with visible recovery paths, practical local ownership, and clear user outcomes |

## Start here

If this is your first time here, start with one of these six:

- [CortexPilot-public](https://github.com/xiaojiou176-open/CortexPilot-public) - the clearest entry point into my AI orchestration and governance direction
- [ui-automation-control-plane](https://github.com/xiaojiou176-open/ui-automation-control-plane) - the control-plane view of browser automation, proof, and release-ready quality gates
- [provenote](https://github.com/xiaojiou176-open/provenote) - traceable writing and research output built around searchable sources and auditable markdown
- [prooftrail](https://github.com/xiaojiou176-open/prooftrail) - inspectable browser automation built for repeatability and recovery
- [sourceharbor](https://github.com/xiaojiou176-open/sourceharbor) - a knowledge pipeline for turning noisy source streams into usable operator context
- [openui-mcp-studio](https://github.com/xiaojiou176-open/openui-mcp-studio) - AI-assisted UI generation with verification and production-minded workflow guardrails

## Recommended paths

- If you care about AI control planes, start with [CortexPilot-public](https://github.com/xiaojiou176-open/CortexPilot-public).
- If you care about browser automation and evidence, start with [ui-automation-control-plane](https://github.com/xiaojiou176-open/ui-automation-control-plane) and [prooftrail](https://github.com/xiaojiou176-open/prooftrail).
- If you care about research workflows, start with [sourceharbor](https://github.com/xiaojiou176-open/sourceharbor), [provenote](https://github.com/xiaojiou176-open/provenote), and [docsiphon](https://github.com/xiaojiou176-open/docsiphon).
- If you care about user-facing AI experiences, start with [openui-mcp-studio](https://github.com/xiaojiou176-open/openui-mcp-studio) and [multi-ai-sidepanel](https://github.com/xiaojiou176-open/multi-ai-sidepanel).
- If you care about local-first macOS tools, start with [apple-notes-snapshot](https://github.com/xiaojiou176-open/apple-notes-snapshot) and [apple-notes-forensics](https://github.com/xiaojiou176-open/apple-notes-forensics).

## Design principles

- Local-first when it improves trust, ownership, and recovery
- Evidence-first when systems make claims about what happened
- Operator-visible instead of demo-only
- Hosted-first public CI with explicit gates for sensitive lanes
- Real workflows over decorative prototypes
